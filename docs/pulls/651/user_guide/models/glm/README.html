Generalized Linear Model (GLM)#

Overview#

A GLM predicts a response by passing a linear combination of the input features through an inverse link function, which gives the mean of an observation distribution such as Poisson for spike counts. NeMoS provides four GLM classes. They differ in the number of outputs and in the type of the response.

A GLM learns one weight vector w for one neuron. A PopulationGLM learns a weight matrix W with one column per neuron. All the neurons share the same predictors X.

A GLM predicts a count or a continuous value for each sample. A ClassifierGLM predicts a discrete label for each sample. It learns one weight column per class. The softmax gives the probability of each class, and the predicted label is the most probable class.

A ClassifierPopulationGLM combines the two: it predicts one label for each neuron.

Basic Syntax#

import nemos as nmo

X, y = nmo.datasets.tuned_poisson()
model = nmo.glm.GLM().fit(X, y)
model.score(X, y)
