How-To Guide#

Task-oriented recipes: each page answers a single “how do I …?” question. The concepts behind them are covered in the user guide.

Additional requirements

To run these guides, you may need to install some additional packages used for plotting and data fetching. You can install all of the required packages with the following command:

pip install nemos[examples]
