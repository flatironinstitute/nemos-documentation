Population Classifier GLM#

ClassifierPopulationGLM predicts discrete labels for several outputs at once, one categorical variable per neuron, through a softmax inverse link. It stands to the ClassifierGLM as the PopulationGLM stands to the GLM: the same model, fit jointly over the neuron axis instead of in a loop.

Fitting a Population Classifier GLM#

The y passed to fit is a two-dimensional array of shape (n_samples, n_neurons), each column holding the labels of one neuron. The number of classes is not inferred from the data, it is declared at initialization with n_classes.

import jax.numpy as jnp
import numpy as np

import nemos as nmo

n_neurons = 3
n_classes = 4
n_samples = 1000

# generate data:
# - X array of shape (n_samples, n_features)
# - labels array of shape (n_samples, n_neurons)
X, labels = nmo.datasets.tuned_categorical(
    n_samples=n_samples, n_neurons=n_neurons, n_classes=n_classes
)
print(f"X shape:      {X.shape}")
print(f"labels shape: {labels.shape}")

# define and fit the model
model = nmo.glm.ClassifierPopulationGLM(n_classes=n_classes)
model.fit(X, labels)

Shape of the parameters#

The model estimates one set of coefficients per class, so the class axis is added last to the parameters.

print(f"coef_ shape:      {model.coef_.shape}")
print(f"intercept_ shape: {model.intercept_.shape}")

coef_ shape:      (32, 3, 4)
intercept_ shape: (3, 4)

coef_ is (n_features, n_neurons, n_classes) and intercept_ is (n_neurons, n_classes), so coef_[:, j, k] are the weights that neuron j assigns to class k. Dropping the class axis from both recovers the shapes of the PopulationGLM, and dropping the neuron axis as well recovers those of the single neuron ClassifierGLM, (n_features, n_classes) and (n_classes,).

The model is over-parameterized. It fits one linear predictor per class, \(n\) of them, to determine \(n\) probabilities that are constrained to sum to one, which is one more than strictly needed: once the first \(n - 1\) probabilities are known, the last one is

\[ p_n = 1 - \sum_{k=1}^{n-1} p_k . \]

The redundancy is an invariance of the softmax, which is unchanged when the same quantity is added to the linear predictor of every class. Without regularization the model therefore has infinitely many solutions, all of them giving the same probabilities. Adding a Ridge regularization prevents that, and that is why Ridge is the default instead of UnRegularized.

The index k of the class axis refers to classes_, the sorted labels observed during the fit.

model.classes_

Array([0., 1., 2., 3.], dtype=float32)

Predicting labels and probabilities#

predict returns labels drawn from classes_, one per sample and neuron, with the class axis consumed by the arg-max.

predicted = model.predict(X)
print(f"predicted shape: {predicted.shape}")
predicted[:5]

predict_proba keeps the class axis and returns the whole distribution. It returns log-probabilities by default, matching the log_softmax inverse link; pass return_type="proba" for probabilities.

proba = model.predict_proba(X, return_type="proba")
print(f"proba shape: {proba.shape}")

Neuron-specific features#

The feature_mask selects the predictors of each neuron, as in the PopulationGLM, with one difference: it carries no class axis. Its shape is (n_features, n_neurons), because a feature either reaches a neuron or it does not, and it cannot be used for one class of a neuron alone.

# drop the first 8 features from the predictors of the first neuron
feature_mask = np.ones((X.shape[1], n_neurons))
feature_mask[:8, 0] = 0

masked = nmo.glm.ClassifierPopulationGLM(
    n_classes=n_classes, feature_mask=feature_mask
)
masked.fit(X, labels)

# zero for every class of the first neuron
masked.coef_[:8, 0]

Scoring#

score returns the mean log-likelihood over samples and neurons, a single number, which is what scikit-learn cross-validation expects from an estimator.

model.score(X, labels)

Array(-1.3833574, dtype=float32)

As for the PopulationGLM, averaging over the sample axis alone leaves one score per neuron.

model.score(X, labels, aggregate_sample_scores=lambda x: jnp.mean(x, axis=0))

Array([-1.3825917, -1.3842756, -1.3832048], dtype=float32)
